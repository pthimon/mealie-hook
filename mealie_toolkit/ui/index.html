Set each meal's size, then check the combined list below against what you have. Sizes start at the default servings, or the whole recipe when it only states a yield; the size you last used for a recipe is remembered. Meals already added start unticked.

Combined list

Everything the ticked meals need, added up. Untick what you already have enough of. Spoonfuls, pinches and handfuls show no amount: they are not bought by the spoon.

Meals

Changes go straight into Mealie's planner. Greyed meals have passed: they are only here to straighten the plan out, and count for nothing.
